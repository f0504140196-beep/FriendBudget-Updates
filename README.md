# FriendBudget Updates

ערוץ העדכונים האוטומטי של FriendBudget.

המאגר הזה מיועד **רק לעדכוני תוכנה**. אין לשמור בו נתוני תקציב, קובצי בנק, פרטי אשראי, מפתחות סנכרון או גיבויים.

FriendBudget מותקנת מקומית במחשב ועובדת גם ללא אינטרנט. כאשר יש חיבור, התוכנה בודקת כאן אם פורסם עדכון חדש ומחילה אותו רק אחרי בדיקות תקינות.

גרסת בסיס: 1.6.0
